# Isoka Lentombi Eyodwa 💕

A modern South African dating app with TikTok integration.

## Features
- User profiles with photos and bios
- Algorithm-based matching
- Real-time messaging
- Live dating on TikTok
- Verification system

## Tech Stack
- **Backend:** Node.js, Express.js
- **Database:** PostgreSQL
- **Frontend:** React.js (Web), React Native (Mobile)
- **Real-time:** Socket.io
- **Live:** TikTok API, Agora SDK

## Getting Started

### Backend
```bash
cd backend
npm install
npm run dev
```

### Environment Setup
Create `.env` file with PostgreSQL credentials
